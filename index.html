Panduan Fitur & Logika Sistem

Mekanisme kerja terperinci dari setiap modul yang ada pada aplikasi SetVeen.

1. Manajemen Dataset Mahasiswa

Input, validasi, dan filter semesta data

Data mahasiswa bertindak sebagai Himpunan Semesta (U):

  • Tambah Data: Klik tombol + Tambah Data, masukkan NIM unik, Nama, Nilai (0–100), Kehadiran (0–100%), dan opsi status organisasi (Ya/Tidak).
  • Filter Cepat: Gunakan filter bar untuk melihat anggota Semesta, Himpunan A, B, C, atau mahasiswa yang tidak masuk himpunan mana pun.
  • Hapus & Reset: Tombol silang (✕) menghapus record, sedangkan tombol ↺ Reset Dataset mengembalikan ke 8 data awal anggota kelompok.

2. Aturan & Kriteria Himpunan

Fungsi keanggotaan diskrit predikat logika

Setiap entitas dievaluasi dengan kriteria logika boolean:

Himpunan A (Nilai Tinggi): nilai ≥ 80
Himpunan B (Aktif Organisasi): organisasi === 'Ya'
Himpunan C (Kehadiran Tinggi): kehadiran ≥ 80%

Pada tab Himpunan, kartu menampilkan kardinalitas aktual beserta daftar terurut nama dan nilai mahasiswa yang memenuhi syarat.

3. Kalkulator & Diagram Venn

Komputasi logika biner dan visualisasi visual

Mendukung operasi biner dan uner dengan rendering interaktif:

  • Operasi Tersedia: Union (A ∪ B), Intersection (A ∩ B), Difference (A − B atau B − A), dan Complement (Aᶜ) terhadap Semesta U.
  • Diagram Venn Dinamis: Visual SVG langsung menyoroti area hasil himpunan dengan warna biru berarsir dan menampilkan kardinalitas irisan & eksklusif.
  • Ekspor & Salin: Tombol ⧉ Salin untuk menyalin format teks, dan ↓ Export CSV untuk mengunduh spreadsheet operasi_himpunan.csv.

4. Sinkronisasi Realtime & Storage

Penyimpanan client-side aman dan instan

Dirancang 100% responsif di sisi browser tanpa dependensi backend:

  • Auto-Persist localStorage: Setiap penambahan atau penghapusan data langsung tersimpan otomatis di peramban Anda.
  • Live Metrics: Angka pada counter badge header, metrik card dashboard, dan daftar anggota himpunan diperbarui serentak secara realtime.

Glosarium Simbol Matematika Diskrit

Notasi formal teori himpunan yang diimplementasikan pada sistem SetVeen

Notasi Standar
Simbol Nama Operasi Definisi Matematis Makna Kontekstual di SetVeen
U Semesta (Universal Set) { x | x adalah elemen semesta } Seluruh data mahasiswa yang terdaftar di dalam sistem.
∪ Gabungan (Union) A ∪ B = { x | x ∈ A ∨ x ∈ B } Mahasiswa yang masuk ke himpunan A atau B (atau keduanya).
∩ Irisan (Intersection) A ∩ B = { x | x ∈ A ∧ x ∈ B } Mahasiswa yang memenuhi kedua syarat sekaligus.
− Selisih (Difference) A − B = { x | x ∈ A ∧ x ∉ B } Mahasiswa anggota A yang bukan merupakan anggota B.
Aᶜ Komplemen (Complement) Aᶜ = { x ∈ U | x ∉ A } = U − A Mahasiswa di Semesta U yang tidak memenuhi kriteria himpunan A.

Pertanyaan yang Sering Diajukan (FAQ)

Jawaban cepat untuk pertanyaan teknis dan operasional SetVeen

? Apakah data saya hilang saat refresh halaman?

Tidak. SetVeen menyimpan dataset mahasiswa langsung di memori lokal peramban (localStorage) sehingga data Anda tetap aman hingga Anda menekan tombol Reset Dataset.

? Bagaimana cara membaca diagram Venn hasil operasi?

Area yang disorot dengan warna biru berarsir menunjukkan anggota hasil operasi yang dipilih. Di setiap segmen tercantum angka kardinalitas mahasiswa yang sesuai.

? Bagaimana cara menyalin atau mengunduh hasil operasi?

Di panel hasil tab Operasi, klik tombol Salin untuk menyalin data ke clipboard atau klik Export CSV untuk mengunduh file spreadsheet operasi_himpunan.csv secara otomatis.

? Apakah bisa kembali ke dataset default awal kelompok?

Bisa. Cukup buka halaman Dataset lalu klik tombol ↺ Reset Dataset di pojok kanan atas untuk memulihkan 6 data mahasiswa anggota Kelompok G.
